Cách tái tạo dataset (Reproducibility)

Mỗi lần retrain, DVC chụp snapshot stream_buffer và liên kết với MLflow Run ID. Để tái tạo dataset của một lần train cụ thể:

  1. Lấy dvc_snapshot_id từ bảng trên hoặc từ MLflow Run tags (dvc_snapshot_id).
  2. Tìm file .dvc tương ứng trong thư mục data/dvc_snapshots/.
  3. Checkout Git commit tại thời điểm đó: git checkout <commit>
  4. Pull data từ MinIO: dvc pull
  5. Dataset khớp 100% với lần train đó. 
# Ví dụ: tái tạo dataset của lần train v5
git checkout <commit-hash-v5>
dvc pull data/dvc_snapshots/
# Dữ liệu stream_buffer của lần train v5 đã sẵn sàng
